Frises

Chaque frise suit son propre bord avec son propre motif. Clique une frise pour la régler, ou glisse un SVG sur sa ligne pour changer son motif.

Empilement
Deux frises qui partagent une partie du même bord se placent l'une au-dessus de l'autre. Des frises jointes bout à bout ne bougent pas.
Un fichier .courbeur garde tout : la forme, les frises, les motifs, les textes et tes polices.

Réglages du motif
A = motif 1, B = motif 2. Par exemple AB, ABB ou AAB. L'ordre se répète tout le long du bord.
Le motif entier est répété puis ajusté pour remplir le bord.
Le motif garde la hauteur visée : il est dupliqué autant de fois que nécessaire pour remplir le bord, sans être étiré ni écrasé.
Le motif ne se replie plus sur lui-même dans les virages serrés : sa base suit le bord, son haut tourne en douceur.
Plus grand = le motif ondule moins dans les petites irrégularités du bord.

Export pour LightBurn
Sur chaque calque, tout ce qui se touche ou se recouvre devient un seul contour propre : pas de trait en double à la découpe, pas de trou dans la gravure. Mets des frises jointes sur le même calque pour qu'elles forment un seul contour.
Le DXF arrive dans un .zip et garde les coordonnées d'origine. Le SVG est en millimètres, avec les couleurs des calques LightBurn choisis.
Le téléchargement n'est pas disponible ici. Copie le DXF puis colle-le dans un fichier texte nommé frise.dxf.
